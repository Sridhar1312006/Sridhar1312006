- 🔭 **Focus:** Digital VLSI Design, RTL coding, and Hardware Acceleration on FPGAs.
- 🌱 **Exploring:** Advanced SoC interconnect protocols (AXI, AHB, APB), Static Timing Analysis (STA), and Computer Architecture (RISC-V/MIPS).
